# Presentation Guide

Status: living document. The final presentation is a mandatory .pptx and PDF, delivered before a separate live MVP demonstration.

## Format
The default sequence is **presentation of process, decisions and architecture → transition → live MVP demo → Q&A**.

The initial draft should be comprehensive rather than prematurely shortened. We will collaboratively refine scope, pacing, slides and wording after the implementation is stable.

## Proposed narrative
1. Assignment and business problem
2. Target users, use case, requirements
3. MVP scope and what is deliberately excluded
4. How AI assisted planning and implementation
5. Architecture diagram and request/data flow
6. Technology selection and alternatives considered
7. Data design, demo dataset and relevance rules
8. AI classification, structured validation and fallback
9. UX and Material Design 3 decisions
10. Testing, errors, privacy and security
11. Key engineering challenges, mistakes and lessons
12. Limitations and roadmap
13. Transition to live demo
14. Questions

## Speaker notes
Write natural German sentences, not a dense technical essay. Explain what, why, alternatives and trade-offs. Every major diagram and screenshot must be traceable to the current repository.

## Evidence rule
Only present implemented functionality and genuinely executed tests as complete. Where relevant, distinguish AI-assisted coding from genuine runtime LLM inference.
