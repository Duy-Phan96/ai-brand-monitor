# Proposed v0.1.0 — AI Brand Monitor MVP

Draft release notes; tag/release not created. Publish only after owner merge/review and acceptance against the approved source.

## Included

- Local SQLite-backed monitoring workspace using only explicitly fictional sample data.
- Data-derived KPIs, UTC activity, sentiment/topics, action triage, combined filters/search/sorting and inspectable recommendations/provenance.
- Responsive MD3-inspired React/MUI interface with German/English controls, persistence and language-aware formatting.
- Validated Gemini adapter with backend-owned model/method metadata and deterministic fallback. New prompts request both analysis languages in one response; switching uses saved wording or honestly labeled classification-derived legacy/rule descriptions without additional requests.
- Safe JSON round trips: fresh database identities and recomputed analysis; unknown/invalid batches rejected atomically. CSV retains original flat evidence fields. Fictional-only, nonblank/valid Unicode and aware-UTC input contracts.
- Fictional seed/reset safety, offline regression/Chromium/axe checks, frontend lockfile, CI, ADRs, engineering journal, acceptance guidance and demo/interview materials.

## Verification

Use the [release preparation report](RELEASE_PREPARATION.md) and checks for the exact approved PR/merge head. Do not copy historical results onto an unverified new release. No live Gemini generation was required for release verification.

## Known limitations

Local interview MVP without authentication, production hardening, live source ingestion, executive summaries or automated replies. Rule classification is English-only and weak on German/negation/sarcasm. Old arbitrary model prose is not faithfully translated; original evidence stays inspectable. Revised bilingual prompt fidelity is not verified live. Imports append duplicates and retain 1–500-record/1 MB browser limits, not faithful database backup restoration. Legacy rows are preserved rather than silently migrated. Reserved-topic aggregation, full accessibility/real-device review, backend advisory scanning and broader scale/resource limits remain follow-ups.

Personal acceptance, final presentation assets and rehearsal are separate owner deliverables. No deployment is included.
