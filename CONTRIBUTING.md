# Contributing

## Branches
Create a focused feature branch from `main`.

Examples:
- `feat/mention-dashboard`
- `fix/filter-reset`
- `docs/demo-script`

## Pull requests
Each PR should state:
- purpose
- implemented changes
- tests actually executed
- documentation updates
- known limitations

## Quality
Keep changes small, typed, tested where appropriate and easy to explain. Never commit secrets or fabricated production data.
